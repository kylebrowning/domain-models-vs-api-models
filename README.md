# Domain Models vs API Models

Separating network concerns from business logic in Swift.

This is the companion project for the blog post: [Domain Models vs API Models in Swift](https://kylebrowning.com/posts/domain-models-vs-api-models)

## Overview

This project demonstrates:

- API models that handle raw server responses
- Domain models with validated, non-optional properties
- Clean transformation between the two layers
- Keeping Codable complexity out of your business logic

## Requirements

- iOS 17+
- Xcode 15+
- Swift 5.9+
